## 1. System Mission & Scope

**Warangal Trading Ring (WTR)** is a high-performance trading simulation platform. Traders submit MARKET orders that are immediately executed against the authoritative 10-second OHLCV candle close prices generated by the continuous simulation engine.

- **Market Execution Model:** Valid MARKET orders are filled immediately in a single atomic transaction. No limit order books, bid/ask matching, or counterparty queues.
- **Zero-Float Precision Standard:** All prices, balances, positions, and financial calculations are executed using `numeric(24, 8)` and `decimal.js` string precision.

## 3. Global Request & Response Standard

Every endpoint complies with the following contract standards:

1. **Prefix:** All HTTP endpoints use `/api/v1/`.
2. **Payload Envelope:**
   ```json
   {
     "data": { ... },
     "request_id": "req_01J8ABC..."
   }
   ```
3. **Error Envelope:**
   ```json
   {
     "error": {
       "code": "INSUFFICIENT_FUNDS",
       "message": "Available cash is insufficient for this order."
     },
     "request_id": "req_01J8ABC..."
   }
   ```
4. **Timestamps:** ISO-8601 UTC with trailing `Z` (e.g. `2026-09-30T10:00:00.000Z`).
5. **Decimals:** Numeric strings with 2 to 8 decimal places (e.g. `"21450.50"`, `"1000000.00"`).
